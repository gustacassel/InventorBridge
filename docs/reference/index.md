## How to use

- Look up a member: `grep` in `members.tsv` (columns: type, member, kind, signature, versions).
- Open `objects/<Name>.md` or `enums/<Name>.md`. Each object page has the interface in pseudo-C#, what returns it, the types it references and an example path from `Application` (one possible path, not the only one; `→ (Type)` is a cast).
- "Inherits from" lists the object's COM ancestors: the interop does not show inheritance, but `PartDocument` is also a `Document`, `ExtrudeFeature` is also a `PartFeature`, and so on.
- Signatures: `object` is a COM VARIANT; `= Missing` marks an optional parameter that can be omitted.
- `// since 20xx` marks members that do not exist in every version listed above.
- The API uses internal units: length in cm, angles in radians, regardless of the document units.
